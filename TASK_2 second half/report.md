# Employee Data Analysis – Project Report

**Date:** 19-11-2026

## 1. Problem
Analyze employee data to identify salary patterns, compare departments, and detect data-quality issues.

## 2. Dataset
A sample dataset of 15 employee records was created for this assignment. After cleaning, 14 unique employee records remained.

Missing values were handled, duplicate records removed, text standardized, and salary outliers identified.

## 3. Three Key Insights
1. **Department analysis:** Sales has the highest average salary at ₹99,125.
2. **City analysis:** Delhi has the highest average salary at ₹1,16,166.67.
3. **Salary distribution:** One unusually high salary of ₹2,50,000 was detected.

## 4. Two Recommendations
1. Review the unusually high salary to confirm whether it is accurate.
2. Compare departmental salary patterns using a larger dataset before making business decisions.

## 5. Limitations
- Only 14 cleaned employee records were analyzed.
- The dataset is synthetic and does not represent actual company employees.
- The salary outlier strongly influences average salary calculations.

## Conclusion
The project demonstrates data cleaning, exploratory analysis, and visualization using Python and Pandas.
