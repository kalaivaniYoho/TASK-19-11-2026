# Employee Data Analysis Project

## Project Overview
This project covers employee data cleaning, exploratory data analysis, visualizations, and reporting using Python.

The project uses a sample employee dataset.

## Requirements
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter
- nbconvert

## Installation
Open the VS Code terminal in the `TASK_2 second half` folder and run:

`py -m pip install -r requirements.txt`

## How to Run
1. Run `TASK_1 first half/main.py` from its folder to clean the employee dataset.
2. Open `TASK_2 first half/employee_analysis.ipynb` and run all cells.
3. Open `TASK_1 second half/visualizations.ipynb` and run all cells to generate five charts.
4. Read `TASK_2 second half/report.md` for the project findings.

Run each task from its own folder.

## Project Outputs
- `clean_data.csv` – Cleaned employee data
- `employee_analysis.ipynb` – Exploratory data analysis
- `visualizations.ipynb` – Five visualizations
- `reports/figures/` – Saved charts
- `report.md` – Project findings and recommendations

## Conclusion
The project demonstrates data cleaning, statistical analysis, visualization, and reporting using Python.
